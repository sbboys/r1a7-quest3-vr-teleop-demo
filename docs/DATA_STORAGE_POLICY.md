1. 用 `findmnt -T /data/threading` 或等效方式确认 `/data` 确为独立挂载的数据分区；不能仅检查目录存在。当前工作站的数据分区为 `/dev/nvme0n1p3`。

3. 检查剩余容量和写权限；明确本次数据目录和输出目录。
4. `/data` 未挂载、空间不足、无写权限或路径解析不正确时，停止该任务并报告，不得自动回退到 `/home/robot`、系统盘 `/tmp` 或当前工作目录。
