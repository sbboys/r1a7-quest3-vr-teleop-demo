交接至少包含：日期、仓库/分支/提交、修改文件、实际命令、测试结果、硬件验证、
未解决问题、下一步和禁止回退事项。需要长期保存的结论必须进入仓库或持久日志，
不能只留在聊天消息或 `/tmp`。
