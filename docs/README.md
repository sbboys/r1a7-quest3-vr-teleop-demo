## 逻辑分类

- `architecture/`：架构、模块和代码解析。
- `operations/`：运行、通信、相机、VR 和真机安全操作。
- `experiments/`：实验参数、现象、结果和结论。
- `source_records/`：Word、PPT 和聊天记录整理稿。
- `archive/`：历史文档和已结束项目说明。

历史文档暂时保留原路径，防止旧启动说明和链接失效。新增文档按上述逻辑分类；物理迁移必须放在独立重构提交中。
