# R1-A7 细线镊子穿孔项目

## 目标

使用 R1-A7 机器人、Dex1-1 夹爪和绑定镊子夹取细线，并在视觉检测和引导下完成穿孔。

## 代码位置

- 主目录：`r1a7_threading_project/`
- 真机/传输控制：`r1a7_threading_project/transfer_control/`
- 视觉：`r1a7_threading_project/vision/`、`r1a7_threading_project/vision_dual_camera/`
- 标定：`r1a7_threading_project/calibration/`
- 控制台：`r1a7_threading_project/console3d/`
- 配置：`r1a7_threading_project/config/`
- 实验记录：`r1a7_threading_project/docs/`

## 状态

当前为主研究项目。真机运行前必须阅读项目 README、通信检查和安全停止说明。
