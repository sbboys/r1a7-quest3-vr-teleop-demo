# R1 A7 细线穿孔项目 GitHub 上传清单

本次上传以 `r1a7_threading_project` 为边界，目的是保留细线夹取与穿孔项目的可复用代码、配置、实验结果和研究资料，并与此前的 ACT 和扳手项目保持目录隔离。

## 上传内容

- `README.md`：项目目标、第一阶段范围和环境复用原则。
- `transfer_control/tools/`：R1-A7 VR/LowCmd 控制工具及端口保护工具。
- `scripts/`：夹爪状态读取、镊子绑定标定和闭合测试脚本。
- `vision/`：头部 RGB 视觉、ROI 跟踪、IK/LowCmd 诊断、局部 Jacobian 和绝对 XY 标定/点击移动程序。
- `config/`：相机、任务阶段和夹爪镊子标定配置。
- `docs/*.md`、`docs/*.json`：工作交接、实验基线、研究路线和对话整理记录。
- `docs/*.pptx`：研究方案汇报版本。
- `docs/ppt_assets/`：汇报中使用的图片和图示素材。

## 明确不上传

- `/data` 下的真机录制数据和大体积数据集。
- Python `__pycache__`、运行日志和临时文件。
- 带有 `.bak` 或 `.backup` 后缀的历史备份脚本。
- 本机 conda 环境；`tv` 和 `aloha` 只作为运行前提，不复制到 GitHub。
- 主仓库中与本项目无关的 ACT、扳手和官方源码修改。

## 重要边界

- 当前已验证的视觉地图是约 40 mm 工作区域的 Homography，RMSE 约 2.141 mm；100 mm 标定曾触发工具姿态漂移保护，不能标记为已完成。
- 头部相机当前只确认 RGB，不能把未验证的深度输入写入运行前提。
- 真机运行时仍需根据现场网卡、机器人 IP、DDS domain 和当前 USB 相机节点复核配置。
- 外部依赖 `R1A7_ArmIK` 和 A7 URDF 位于本机运行目录，本次只上传调用方代码和路径说明，不复制外部运行时目录。
