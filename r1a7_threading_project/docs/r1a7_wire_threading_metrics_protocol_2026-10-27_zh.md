# R1-A7 细线夹取与穿孔研究指标协议 v1

日期：2026-10-27

适用范围：桌面近距离、低速、准静态的细线识别、夹取、对孔与穿孔研究

验证状态：**协议与离线工具已建立；本文阈值均为候选验收门，不代表真机已达标**

## 1. 结论

本课题不能只用“识别到了”“机器人动了”或单次穿孔成功来评价。研究指标必须分成五层：

1. 感知精度与连续性；
2. 感知到控制的时序性能；
3. 机器人末端实际运动与保持性能；
4. 夹持稳定性和细线状态；
5. 任务成功率、耗时、恢复和安全。

机器人末端运动精度、相机识别精度都可以作为指标，但二者不能互相替代。图像中的像素误差只有经过独立标定或外部真值验证后，才能写成毫米精度；控制器的指令位置也不能直接当作末端实际位置。

当前仓库已经具备视觉状态 JSON 和控制器轨迹 CSV 的一部分字段，但尚缺少统一试次编号、独立真值、穿出量、夹持滑移和真实停止距离。正式实验应先补齐这些数据链，再发布系统级精度或成功率结论。

## 2. 事实状态分级

所有实验结论必须带状态标签：

| 状态 | 含义 | 可否写成研究结论 |
|---|---|---|
| `VERIFIED` | 有原始数据、独立判据、重复试次和可复算统计 | 可以，必须附条件和样本数 |
| `OBSERVED` | 操作员观察或单次日志支持，但无充分重复/真值 | 只能写“观察到” |
| `CANDIDATE` | 待验证的阈值、标定或算法设置 | 不可写成已达到 |
| `PLANNED` | 方案或后续工作 | 不可写成已实现 |
| `UNKNOWN` | 缺少记录或结果标签 | 不作正负判断 |

当前已知边界：

- `10 mm/s` 是当前普通笛卡尔基线及历史成功试次的配置，不是末端精度；
- `30 Hz / 250 Hz` 是 IK/LowCmd 频率，不是相机或穿孔精度；
- `20 µm / 200 µm` 是研究对象尺寸，不是系统误差；
- 当前数据不能证明系统达到 `0.1 mm` 精度，也不能证明最终成功率达到 `90%`；
- 左腕 007Z 与外部相机镊尖标定仍是候选标定；双相机夹线栈仍默认 Shadow。

## 3. 正式实验前必须冻结的条件

每一批可比较实验都要记录并冻结：

- 细线：直径、材料、刚度/批次、露出自由长度、是否预弯、夹持位置；
- 孔件：实际孔径、厚度、倒角、材质、安装姿态和批次；
- 夹持：夹爪命令端点、镊子安装、夹持力代理量、初始滑移检查；
- 相机：型号/序列号、镜头、分辨率、帧率、曝光、增益、光源和标定文件哈希；
- 控制：代码提交、控制器入口、速度/加速度、视觉模式、增益、超时和最大恢复次数；
- 真值：测量设备、分辨率、标定日期、同步方法和不确定度；
- 成功判据：穿出量、是否允许接触、超时、恢复次数和安全停止条件。

几何余量按下式记录：

```text
c = (D - d) / 2
```

其中 `D` 为孔径、`d` 为细线直径、`c` 为单边径向间隙。直线刚性近似下，进入孔口的必要条件可写为：

```text
e_perp + t * tan(|alpha|) < c
```

其中 `e_perp` 是横向对准误差，`t` 是孔件厚度，`alpha` 是线方向与孔轴的夹角。柔性线会弯曲，因此该式用于设计误差预算和筛查，不作为最终成功判据。

## 4. 指标字典

### 4.1 感知层 P

| ID | 指标 | 定义/统计 | 单位 | 候选门槛 |
|---|---|---|---|---|
| P01 | 细线分割 IoU | 预测掩膜与人工真值交并比，按条件分别统计 | 0–1 | `>=0.80` |
| P02 | Dice / Precision / Recall | 像素级，必须同时报告，避免只优化面积重叠 | 0–1 | 先建基线 |
| P03 | 中心线连通性 | 断裂段数、最长连续段比例；可辅以 clDice | 次、0–1 | 先建基线 |
| P04 | 镊尖定位误差 | 与独立人工/标定真值的欧氏距离 | px；验证后 mm | 报均值/P95/最大值 |
| P05 | 孔中心/孔轴误差 | 中心位置和可见方向相对独立真值 | px、deg；验证后 mm | 报均值/P95/最大值 |
| P06 | 有效观测率 | 有效帧数 / 应采帧数；正常、遮挡、反光分开 | % | 正常可见 `>=95%` |
| P07 | 错误接受率 | 无效或错误状态被标为 valid 的帧/事件比例 | % | 越低越好，单列 |
| P08 | 连续丢失时间 | 一次有效状态中断的持续时间 | ms | 报 P95/最大值 |
| P09 | 相对视觉测量误差 | 镊尖—孔相对量与独立真值之差 | mm | P95 `<=0.05`，仅在真值链确认后启用 |

细线属于细长拓扑结构，只报告 IoU 可能掩盖“面积相似但中间断线”的失败，所以必须增加连通性指标。

### 4.2 时序层 C

| ID | 指标 | 定义/统计 | 单位 | 候选门槛 |
|---|---|---|---|---|
| C01 | 有效更新率 | 单位时间内通过有效性与新鲜度检查的观测数 | Hz | `>=20 Hz` |
| C02 | 采集到控制延迟 | 帧采集时间到控制器消费时间；同一时钟或校准时钟偏差 | ms | P95 `<=100 ms` |
| C03 | 融合时间差 | 外部/腕部配对帧时间戳之差 | ms | 报 P50/P95/最大值 |
| C04 | 指令到实际响应延迟 | 指令变化到独立测得运动响应的时间 | ms | 先建基线 |

延迟必须和速度一起解释。例如 `10 mm/s × 0.1 s = 1 mm`，若端到端延迟达到 100 ms，仅延迟对应的行程就可能大于亚毫米级余量。

### 4.3 机器人运动与闭环层 M

横向对准误差：

```text
e_perp = sqrt((x_tip - x_hole)^2 + (y_tip - y_hole)^2)
```

保持抖动：

```text
J_hold = sqrt((1/M) * sum(||r_k - mean(r)||^2))
```

卡滞占比：

```text
R_stall = T_stall / T_active * 100%
```

其中卡滞事件必须同时满足“有效非零命令”“实际速度/位移低于阈值”“持续超过设定时间”，不能把等待视觉、主动保持或安全停止算成卡滞。

最大跳变偏差：

```text
J_delta = max(||delta_p_actual,k - delta_p_ref,k||)
```

| ID | 指标 | 统计 | 单位 | 候选门槛 |
|---|---|---|---|---|
| M01 | 实际横向对准误差 | 均值/P95/最大值，须由独立真值得到 | mm | P95 `<=0.10 mm` |
| M02 | 可观测方向误差 | 细线方向与孔轴夹角 | deg | P95 `<=2 deg` |
| M03 | 收敛时间/收敛率 | 进入误差带并持续规定时间 | s、% | 先建基线 |
| M04 | 超调量 | 首次进入误差带后的最大偏离 | mm | 先建基线 |
| M05 | 保持抖动 | 对准后 2 s 的位置 RMS | mm | `<=0.03 mm` |
| M06 | 实际速度跟踪误差 | 实测速度与参考速度之差 | mm/s | 报均值/P95 |
| M07 | 卡滞占比 | 按上述联合判据计算 | % | `<=5%` |
| M08 | 跳变次数/最大跳变 | 超过预注册阈值的意外位移 | 次、mm | 0 次严重跳变 |
| M09 | 轨迹重复性 | 同条件终点/轨迹离散度 | mm | 按 ISO 9283 思路报告，不等同设备标称精度 |

微动资格实验使用 `0.2 / 0.5 / 1.0 mm/s` 三档；普通 `10 mm/s` 基线不能直接代表接触插入速度。每档应分别报告实际速度和卡滞，不能仅记录命令值。

### 4.4 夹持层 G

| ID | 指标 | 定义 | 单位 | 候选门槛 |
|---|---|---|---|---|
| G01 | 初次夹取成功率 | 单次闭合后细线被夹住且未切断 | % | 先建基线 |
| G02 | 夹持滑移 | 规定保持/运动后，细线相对镊尖位移 | mm | 报 P95/最大值 |
| G03 | 姿态漂移 | 保持期间细线方向变化 | deg | 报 P95/最大值 |
| G04 | 线损伤率 | 切断、压伤、永久折弯事件比例 | % | 严重损伤为 0 |
| G05 | 夹持稳定率 | 规定运动序列后仍满足位置/姿态范围 | % | 先建基线 |

夹爪命令值、镊尖开度、夹持力代理量、滑移和断线风险必须分别记录。当前右夹爪默认闭合端点 `-0.20` 只能作为调试起点，不能直接当作“最大、安全、稳定夹持”。

### 4.5 任务与安全层 T/S

首次成功率：

```text
R_first = N_first_success / N_trials * 100%
```

有限恢复后的最终成功率：

```text
R_final = N_success_within_limits / N_trials * 100%
```

| ID | 指标 | 定义/统计 | 单位 | 候选门槛 |
|---|---|---|---|---|
| T01 | 首次穿孔成功率 | 不含恢复的独立试次成功比例，附 Wilson 95% CI | % | `>=80%` |
| T02 | 最终穿孔成功率 | 最多 2 次恢复内成功，附 Wilson 95% CI | % | `>=90%` |
| T03 | 完成时间 | 开始授权到成功/失败终止 | s | 候选超时 60 s；报中位数/P95 |
| T04 | 恢复次数与成功率 | 每次回退、重对准、重试都计数 | 次、% | 最多 2 次 |
| T05 | 穿出量 | 线端从孔背面伸出的独立测量长度 | mm | 候选成功阈值 `>=2 mm` |
| T06 | 扰动成功率 | 预注册遮挡/光照/初始偏差条件下最终成功 | % | `>=80%` |
| S01 | 异常到 STOP 命令延迟 | 异常判定时间到零速/停止命令时间 | ms | `<=100 ms` |
| S02 | 真实停止距离 | STOP 命令后末端的物理过行程 | mm | 必须实测后定门槛 |
| S03 | 安全停止率 | 应停止事件中正确触发停止的比例 | % | 目标 100% |
| S04 | 误停率 | 正常试次被错误停止的比例 | % | 单列报告 |

一个“独立试次”必须从统一初始条件开始。视频帧、控制周期和多次恢复不能冒充多个样本。成功判据需同时满足：在时限和恢复次数内、无安全停止/线损伤、独立观测确认穿出量达到冻结阈值。

## 5. 分阶段门控

只有上一阶段达到预注册门槛，才进入下一阶段：

| Gate | 阶段 | 最低证据 | 是否允许运动 |
|---|---|---|---|
| G0 | 条件与真值冻结 | 工件实测、标定哈希、时钟方案、成功/失败代码表 | 否 |
| G1 | 离线感知 | 标注集、按条件的分割/定位/连通/错误接受结果 | 否 |
| G2 | 在线 Shadow | 双相机首帧、有效率、延迟、融合时间差和连续丢失 | 控制输出为零 |
| G3 | 无接触微动 | 独立外测的末端速度、对准、抖动、卡滞和停止距离 | 仅短行程低速 |
| G4 | 夹持稳定 | 夹取、保持、滑移、姿态和损伤数据 | 有限夹爪/短行程 |
| G5 | 完整穿孔 | 随机化重复试次、视频、全链日志、成功率与 CI | 有限恢复的完整任务 |

建议预实验每个条件不少于 10 次，只用于发现协议问题和估算方差；正式关键条件每个方法/条件不少于 50 个独立试次。方法顺序随机化或交错执行，所有失败、超时、人工接管和安全停止都必须保留。

## 6. 实验矩阵

正式论文或阶段报告至少包含以下比较：

1. 感知算法：传统方法、SAM2/U-Net/改进方法在同一图像、标签、ROI、硬件和分辨率下比较；
2. 相机模式：`EXTERNAL_ONLY`、`WRIST_ONLY`、`DUAL`，不得混用不同可见性条件；
3. 视觉控制：固定增益与分阶段增益/速度调度；
4. 低速控制：当前基线与参考平滑、姿态约束、执行反馈组合；
5. 阶段判定：只按几何误差切换，与结合观测有效性/执行状态的切换；
6. 消融：去掉输入增强、工具类别、连通性约束、后处理、速度分层、死区、姿态约束或参考平滑。

每种方法都要使用同一试次集合或同分布随机条件。建议至少按光照、遮挡、反光、初始横向偏差、初始角度、线自由长度和孔件批次分层报告。

## 7. 失败分类

`failure_code` 使用固定枚举，不允许只写自由文本：

- `PERCEPTION_WIRE_LOST`
- `PERCEPTION_TIP_LOST`
- `PERCEPTION_HOLE_LOST`
- `FALSE_VALID_STATE`
- `CAMERA_STALE_OR_DESYNC`
- `ALIGNMENT_NOT_CONVERGED`
- `ARM_STALL`
- `ARM_JUMP_OR_OSCILLATION`
- `GRASP_MISS`
- `WIRE_SLIP`
- `WIRE_DAMAGE`
- `CONTACT_JAM`
- `MISSED_HOLE`
- `TIMEOUT`
- `SAFETY_STOP`
- `OPERATOR_ABORT`
- `LOGGING_INVALID`
- `OTHER`

优先记录最早导致试次不可继续的根因，同时在 `notes` 中保留后续现象。`LOGGING_INVALID` 不计为成功，但应单独报告，不能静默删除后重做。

| 控制器诊断 CSV：循环周期、方向、IK 时间、笛卡尔速度/滞后、实际 q/dq/tau、命令/实际 XYZ、Jacobian 指标 | C04、M03–M09 | 末端量来自机器人模型/状态，不是独立外部真值 |

| 历史 10 mm/s Test02 | 单次 `OBSERVED` 任务成功基线 | 不能计算可靠成功率或推广到 15/25 mm/s |

必须新增或统一：`trial_id`、`condition_id`、`method_id`、工件实测值、标定哈希、视频/日志路径、独立真值时间戳、穿出量、夹持滑移、停止距离和失败代码。

本仓库提供：

- 配置：`config/wire_threading_metrics_v1.yaml`；
- 逐次记录模板：`docs/templates/wire_threading_trial_v1.csv`；
- 离线汇总：`scripts/analyze_wire_threading_trials.py`。

离线汇总采用最近秩 P95 和 Wilson 95% 二项比例置信区间。正式报告必须同时给出分子/分母与区间，不能只报百分比。

## 9. 文献与标准如何量化

- ISO 9283 将工业机器人性能评价拆为位姿准确度、位姿重复性、距离准确度、轨迹准确度、超调和稳定时间等标准化测试。它适合指导 M 类指标的测量设计，但本课题仍需独立外部测量，不能拿控制器内部估计直接宣称 ISO 精度。
- NISTIR 8090 将装配能力按检测、对准、抓取、重定位和插入等过程拆分，并强调成功、时间、间隙、力/接触等任务指标。本文 P/G/M/T 分层沿用这种“分步骤 + 端到端”的思想。
- T-NT 针线穿孔研究报告不同线径/孔条件下的任务成功率，并与视觉伺服基线比较；这说明成功率必须连同线径、孔几何、方法和试次数报告，不能只给总体平均。
- 柔性线性物体插入研究改变材料柔性和环姿态，并分别报告仿真和真实成功率；这支持把线材、自由长度、孔姿态和 sim-to-real 分开作为条件变量。
- clDice 面向管状结构的拓扑保持评价，适合作为细线连通性的补充指标，但不能替代端点误差和任务成功率。

## 10. 下一步执行顺序

1. 实测并冻结线径、孔径、孔厚、倒角、自由长度和成功穿出量；
2. 选定独立真值方法，先量化其分辨率和不确定度；
3. 给视觉 JSON、控制 CSV 和视频使用同一个 `trial_id`，全部保存到持久目录；
4. 完成 G1 离线标注和 G2 Shadow 时序统计；
5. 在明确真机测试授权和实时安全检查后，再做 G3 无接触微动；
6. 夹持稳定达到预注册条件后做 G4；
7. 最后执行随机化的 G5 穿孔试验并用仓库脚本复算成功率、P95 和置信区间。

本文仅建立指标、数据结构和分析口径，没有执行相机采集、机械臂运动、夹爪闭合或完整穿孔验收。
