# R1-A7 三维手动操控台

该操控台使用 Three.js 和 URDFLoader 显示官方 A7 URDF 与双 Dex1-1 可动夹爪模型，使用现有 `r1a7_cartesian_stream_control.py` 控制真机。三维模型的手臂关节和夹爪开度均由真机 LowState 数据驱动，而不是仅做按钮动画。控制台支持右臂笛卡尔 Jog、左右臂 14 个关节独立 Jog，以及左右夹爪的张开、保持和闭合。

## 启动

```bash
cd /home/robot/unitree_sim_isaaclab_threading
PYTHONNOUSERSITE=1 /home/robot/miniconda3/envs/tv/bin/python \
  r1a7_threading_project/console3d/server.py --host 127.0.0.1 --port 8097
```

浏览器打开 `http://127.0.0.1:8097`。

## 界面布局

- 桌面模式下，左侧数字孪生区始终保持 `1:1` 方形，边长采用 `min(45vw, 67vh)`，在常见桌面比例下约占整个界面面积的 `25%`。
- 运行日志位于方形模型和遥测信息下方；右侧顶部是连接参数横栏，中部并排显示笛卡尔点动和单关节点动，底部是双夹爪控制横栏。
- 常用桌面分辨率下页面本身不滚动，所有操作区同时可见；只有左侧运行日志框保留独立滚动。
- 当窗口宽度低于 `840 px` 或高度低于 `680 px` 时，界面才切换为可滚动的窄屏布局。

## 操作顺序

1. 保持急停可用并清空手臂工作区。
2. 设置机器人网卡、本机 IP、X/Y 步长、Z 步长、关节步长、夹爪速度、末端速度/加速度和关节连动周期。首次关节测试使用 `0.5°`；末端连续点动默认使用 `8 mm/s`、`20 mm/s²`。VR 等价执行基线强制关闭右臂重力前馈，界面值保持为 `0`。
3. 点击“启动控制进程”，等待状态变为“等待 ENABLE”。
4. 点击 `ENABLE`，确认状态变为“已连接真机”。
5. 短按末端方向按钮执行一个步长的平滑点动；按住超过约 `180 ms` 后切换为连续速度点动，松开后按设置的加速度平滑减速。单关节点动区可切换左臂/右臂，每一行的 `−`、`+` 对应电机角度减小、增大，不等同于固定的空间方向。夹爪操作使用单击，不需要按住。
6. 使用“停止”退出底层 LowCmd 控制进程。

绿色球表示真机实际 TCP，橙色球表示连续控制目标 TCP。状态区显示跟踪误差和指令速度；跟踪误差达到保护阈值时，连续点动会停止继续推进命令。

## 控制模式与安全约束

- 笛卡尔按钮通过全臂 IK 改变右臂末端位置；关节按钮直接改变指定关节的角度目标。
- 末端短按目标始终从按下瞬间的真机实测 TCP 向前看一个步长；快速连续点击会刷新这一个步长的前视目标，不再把多个 `5 mm` 指令累计成几十毫米的待执行队列。
- 末端长按不重复发送位置步长，而是发送开始/心跳/停止命令，由底层 `30 Hz` IK 循环生成加减速受限的连续速度轨迹。浏览器每 `150 ms` 发送心跳，底层超过 `350 ms` 未收到心跳会自动减速停止。
- “前上方 +X+Z”同时支持短按和长按，X、Z 在同一个 IK 周期内按平面步长与垂直步长的比例同步推进。依次使用“上 +Z”和“前 +X”也应保持各自的单轴直线：每次开始新方向时，控制器从真机实测 TCP 重新建立起点，并锁定未操作的坐标轴，不再继承上一段轨迹的积压误差。
- 连续笛卡尔控制锁定当前的末端旋转基准；程序启动时使用启动姿态，从单关节模式切回笛卡尔模式时则从真机实测关节位置重新采集末端位置和旋转。因此手动调整腕部俯仰后，再执行 X/Y/Z 点动不会回到旧的启动姿态。状态区的“姿态误差”表示实测末端旋转相对当前锁定目标的角度误差。
- 笛卡尔 IK 执行链与已验证 VR 脚本保持一致：每个 `30 Hz` 周期都以真机实测 `arm_q/arm_dq` 求解，IK 解直接交给 `250 Hz` LowCmd 限速输出层。控制台不再叠加第二个关节空间二阶跟踪器，也不再使用延迟的内部目标作为下一周期 IK 初值。
- 连续按键使用实测末端附近的速度伺服目标：虚拟目标在当前活动轴子空间内最多领先实测末端 `12 mm`，不会缩放未操作轴并把单轴直线扭成斜线。单击点动仍保留原来的有限目标移动方式。
- IK 滤波历史只在 `ENABLE` 或从单关节模式重新进入笛卡尔模式时校准；普通的 X/Y/Z 方向切换不会重置 VR 内部平滑器。开始新方向仍会把 LowCmd 输出目标同步到真机实测关节，清除上一方向的输出积压。
- VR 等价基线将手臂力矩前馈强制设为 `0`，与已验证 VR LowCmd 输出一致。界面的重力补偿输入暂不参与控制，后续必须单独验证后才能重新启用。
- 连续点动不再设置每次长按 `80 mm` 的人为行程上限。界面的“构型条件”来自完整右臂 `6x7` 雅可比矩阵；数值达到 `500` 时，继续向前、向上或前上运动会停止并记录 `[KINEMATIC BOUNDARY]`，此时使用“后 -X”退出奇异区。若真机 TCP 暂时没有沿请求方向推进，控制器只记录 `[PROGRESS WARNING]`，不再误判为运动范围终点并重锚；总跟踪误差大于 `25 mm` 持续 `0.4 s` 时仍会停止。此保护不能替代人工急停。
- 针对真机在固定末端姿态下“向前下沉、向上丢失前伸”的现象，代码保留了有界笛卡尔误差补偿的隔离实现，但在 `2026-09-18` 真机启动异常后已将默认增益设为 `0`，不再参与控制。异常原因是早期实现把临时 IK 补偿写回名义命令矩阵，形成逐周期累积；当前实现已改为独立副本，并限制为只有方向键保持按下时才可能启用。在完成离线回放和静止启动验证前，不重新启用该实验功能。
- 两种模式共用同一个 `rt/lowcmd` 发布进程，不会创建第二个控制者。首次按下关节按钮时锁定当前命令姿态；从关节模式切回笛卡尔模式时，以当前实测关节姿态重新计算 TCP，避免回跳到旧目标。
- 单次关节命令默认只改变 `0.5°`，按住时按“重复周期”继续发送离散步进。所有目标受官方 A7 URDF 上下限及 `2°` 软件安全余量限制，并继续受底层 `--max-joint-speed` 限速。
- `+`/`−` 表示关节坐标角度的正向/反向。实际连杆在空间中的运动方向取决于左右臂、当前姿态和关节轴定义，首次必须逐关节短按确认。
- 软件关节限位不能替代自碰撞、环境碰撞和奇异位形检测。测试时保持急停可用，一次只操作一个关节。

## 夹爪控制与安全约束

- 左夹爪使用当前官方 LowCmd 标定范围：张开 `4.86`，闭合 `-0.08`；右夹爪绑定镊子，使用实测标定范围：张开 `0.1585`，闭合 `-0.0500`。
- 三维夹爪使用官方 Dex1-1 两个滑动指关节。前端将左右电机的实测值分别按上述标定范围归一化，并映射到 Dex1-1 URDF 的 `-0.02`（张开）至 `0.0245`（闭合）；因此左右夹爪电机量程不同也能显示为一致的物理开度。
- 当前三维模型显示 Dex1-1 本体开合，右侧实际安装的镊子尚未作为独立几何模型加入；镊子的尖端间距仍以实物标定为准。
- 点击 `ENABLE` 时，两个夹爪均从 LowState 实测位置接管并保持，不会自动跳到张开或闭合目标。只有点击对应按钮后才改变目标。
- “保持”会立刻把对应夹爪的实测位置设为新的命令位置，用于中止尚未完成的张开或闭合。
- 夹爪目标由 250 Hz LowCmd 输出层按设置速度平滑逼近。闭合遇到细线或机械阻挡时，接触检测会转入接触保持，界面显示“接触保持”。
- 左夹爪和右侧镊子都属于同一个 LowCmd 控制会话；不要同时运行 Dex1 服务控制或其他夹爪发布程序。

## 软件结构

- `server.py`：本地 HTTP/WebSocket 服务和真机控制子进程管理。
- `static/app.js`：Three.js 场景、A7/Dex1 模型挂载、遥测、笛卡尔 Jog、单关节 Jog 和夹爪开度映射。
- `model/A7.urdf`、`model/meshes/`：来自宇树 R1-A7 本地官方 SDK 的模型快照。
- `model/A7_Dex1_console.urdf`：保留 A7 运动学，仅将原先包含固定夹爪的腕部末端网格替换为独立腕部外壳的控制台模型。
- 左右 Dex1 安装变换分别补偿原 A7 腕偏航关节约 `+22.25 mm`、`-21.70 mm` 的 Z 向结构偏置，使 5010 腕部外壳和夹爪基座与各自手臂末端对齐；该补偿只影响三维显示，不改变真机控制关节值。
- `model/dex1_1/`：宇树官方 Dex1-1 URDF 与网格快照，运行时分别挂接到左右腕部。
- `transfer_control/tools/r1a7_cartesian_stream_control.py`：实际 IK 与 LowCmd 执行层。
